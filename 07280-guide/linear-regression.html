Part II · Chapter 8

Linear regression

By the end of this page you can derive the least-squares line from scratch — twice, by completing the square and by calculus — write down the normal equations $\theta^\star=(X^\top X)^{-1}X^\top y$ and say exactly when they break.

Why anybody fits a line

Start with the least glamorous possible situation. Your input space is $\X = \R$: one real number per example. Your label space is $\Y = \R$: one real number per example. You have $N$ training pairs

$$\D = \{(x^{(1)},y^{(1)}),\ (x^{(2)},y^{(2)}),\ \dots,\ (x^{(N)},y^{(N)})\}.$$

Notation, first time: the superscript in $x^{(i)}$ is an index, not a power. $x^{(3)}$ is the third training input, not $x$ cubed. The course writes it in parentheses precisely so it can't be confused with an exponent, and later — when inputs become vectors — $x^{(i)}_j$ will mean "the $j$-th coordinate of the $i$-th sample".

The professor's running example is selling a used car. You scrape eight listings for a Pontiac Vibe and record mileage $x$ and asking price $y$:

mileage $x$ (miles)25,00034,00045,00070,00093,000110,000125,000160,000
price $y$ (USD)23,00028,00022,00022,00012,5005,5005,0004,000

Plot it and the eye immediately does something: it draws a line through the cloud. The whole chapter is the machine version of that reflex. Let's fit a line.

Figure 1 · The data, the best line, and the residuals it leaves behind
What to notice: the line does not pass through a single data point. Every point contributes a residual — the vertical gap $y^{(i)}-h(x^{(i)})$, drawn as a segment. Fitting a line means choosing the line that makes these segments collectively small. Vertical, not perpendicular: we are predicting $y$ from $x$, so only error in $y$ counts.

Reason one: it is the simplest honest thing to do

When $\Y=\R$ you have to output a number. The very simplest family of functions that outputs a number and actually responds to the input is a line. It has two knobs. You can compute its optimum in closed form on a napkin. And — this is the part that surprises people — it works startlingly often. Price vs. mileage, yield vs. fertiliser, run-time vs. input size: over a limited range, almost everything looks linear. Linear regression is a classical technique, older than computers, and it has not been retired.

Reason two: the last layer of a neural network is a linear model

This is the reason that should make you care, and it deserves unpacking, because the notes state it in three lines and move on.

Take a deep network that somebody already trained — an image model, a language model, anything. Structurally it is a long stack of layers followed by one final layer that produces the output. Write it as

$$\text{network}(x) \;=\; \underbrace{\phi(x)}_{\text{everything but the last layer}} \ \longrightarrow\ \underbrace{\phi(x)^\top w + b}_{\text{the last layer}}.$$

Here $\phi$ maps a raw input (pixels, tokens) to a $d$-dimensional vector of features — often called the embedding, or the penultimate activations. The last layer takes that vector and produces the answer.

Now you want to use this network for a new task, and you have only a few hundred labelled examples — nowhere near enough to retrain millions of parameters. The standard move: freeze $\phi$ and retrain only $w$ and $b$. This is called linear probing, or "last-layer fine-tuning".

Key idea

Once $\phi$ is frozen, the numbers $\phi(x^{(i)})$ are just fixed data. Call $z^{(i)}=\phi(x^{(i)}) \in \R^d$. The learning problem you are left with is

$$\argmin_{w,b}\ \frac1N\sum_{i=1}^N \left(y^{(i)} - \big(z^{(i)\top}w + b\big)\right)^2,$$

which is exactly the linear regression problem of this chapter, with $z$ in place of $x$. Nothing about the network survives except a table of feature vectors. With real-valued labels, fine-tuning the last layer is least squares.

Three consequences worth carrying with you:

  • It is absurdly cheap. No backpropagation, no gradient descent, no epochs. You build one matrix and solve one linear system. Seconds, on a laptop, for a model that cost millions of dollars to pretrain.
  • It works with tiny $N$. You are fitting $d+1$ numbers, not $10^9$ of them.
  • It is how researchers measure representations. "Linear probe accuracy" is the standard way to ask how much information did this network's features actually encode? — you freeze the network, fit a linear model on top, and report its error. If a linear model can read the answer off the features, the features contain it.
Analogy

The frozen network is a very expensive pair of glasses that someone else ground for you. It turns the blurry world into a crisp $d$-dimensional description. You are not regrinding the lenses. You are just deciding how to read what you now see — and reading, when the answer is a number, is a weighted sum.

Where the analogy breaks: glasses are task-neutral, and a frozen network is not. Its features were shaped by the task it was pretrained on. If your new task needs information the pretraining threw away, no linear layer on top can recover it, and you must unfreeze. Linear probing tells you whether that's necessary.

The hypothesis class: two numbers

Recall from the ML formulation chapter that a learning problem is fixed by choosing a hypothesis class $\H$ — the set of functions we allow ourselves to return — and a loss. Here:

Definition

$\H$ is the set of all functions $\R \to \R$ that can be written as a line. Each member is pinned down by two real parameters $w \in \R$ and $b \in \R$:

$$h_{w,b}(x) \;=\; x\cdot w + b.$$

$w$ is the slope — how many units of $y$ you get per unit of $x$. $b$ is the intercept or bias — the value of $h$ at $x=0$. (In algebra class this was $y = mx + c$; machine learning writes $w$ for "weight" and $b$ for "bias". Same line.)

Because a hypothesis is completely determined by $(w,b)$, searching over $\H$ is searching over $\R^2$. That swap — from "search a space of functions" to "search a space of numbers" — is what makes the problem solvable, and it is the move that every parametric model in this course makes.

Common mistake

"$h(x)=wx+b$ is a linear function." In the linear algebra sense it is not: a linear function must satisfy $f(\alpha x + \beta v)=\alpha f(x)+\beta f(v)$, which forces $f(0)=0$, and $h(0)=b \neq 0$. A line-plus-constant is an affine function. Geometry and machine learning both say "linear" loosely and mean affine; linear algebra means it strictly.

And here's the twist that matters more: which variable are we talking about? $h(x)=wx+b$ is affine in $x$ — but if you hold the data fixed and treat the parameters as the variables, $f(w,b)=wx+b$ is genuinely linear in $(w,b)$, with no constant term. In ML the parameters are the variables and the data is constant. That's why $f(x)=w_2x^2+w_1x+b$, a quadratic in $x$, still counts as a "linear model": it is linear in $w_2,w_1,b$. Hold that thought until feature engineering.

ERM with squared loss

We need a number that says how bad a candidate line is. Follow the pre-reading's own path, which tries three things:

For each point the error is $\text{err}^{(i)} = y^{(i)} - \hat y^{(i)}$ where $\hat y^{(i)} = wx^{(i)}+b$ is the prediction. That gives $N$ numbers; we need one.

  • Attempt 1 — sum the errors, $\sum_i \text{err}^{(i)}$. Fails. Errors carry signs. A line that misses one car by $+\$15{,}000$ and another by $-\$15{,}000$ scores a perfect $0$. You can make a catastrophic line look flawless by balancing its mistakes.
  • Attempt 2 — mean absolute error, $\frac1N\sum_i |\text{err}^{(i)}|$. Acceptable. Signs can no longer cancel. But $|\cdot|$ has a corner at $0$, so it is not differentiable there, and it admits no closed-form minimiser.
  • Attempt 3 — mean squared error, $\frac1N\sum_i (\text{err}^{(i)})^2$. Preferred. Squaring kills the sign too, and it is smooth everywhere.

So the loss is $\ell(y,\hat y) = (y-\hat y)^2$ — squared loss — and empirical risk minimisation reads:

Definition $$\argmin_{h \in \H}\ \frac1N\sum_{i=1}^{N}\Big(y^{(i)} - h\big(x^{(i)}\big)\Big)^2$$

Reading it symbol by symbol: over all lines $h$ in our class, find the one minimising the average over the $N$ training points of the squared gap between the true label $y^{(i)}$ and the prediction $h(x^{(i)})$. The $\frac1N$ makes it a mean rather than a sum, so the number doesn't grow just because you collected more data.

Why squaring is the natural choice for real-valued labels

  1. It removes the sign without removing smoothness. That is the whole job, and it does it with a polynomial.
  2. It punishes big misses disproportionately. Doubling an error quadruples its contribution. One car priced $\$20{,}000$ wrong hurts more than four cars priced $\$5{,}000$ wrong — usually what you want, since a wild prediction is worse than several mediocre ones.
  3. It is differentiable everywhere, so the calculus of Chapter 9 applies, and — as this chapter will show — it yields a closed form. Absolute error does not.
  4. Its unconstrained minimiser is the mean. If you ignore $x$ entirely and just pick a constant $c$, $\argmin_c \frac1N\sum_i(y^{(i)}-c)^2 = \bar y$. Squared loss is the loss whose answer is "the average", which is exactly the summary you want for a real-valued quantity. (Absolute error's answer is the median — a perfectly good but different question.)

We often report the square root, $\text{RMSE}=\sqrt{\text{MSE}}$, because it lives in the units of $y$. For our eight cars the best possible line has $\text{RMSE} \approx \$3{,}156$: "typically off by about three thousand dollars".

Common mistake

Squared loss' sensitivity to big errors is a feature and a bug. One mistyped listing — a $\$250{,}000$ Vibe — will drag the fitted line noticeably, because that single point contributes an enormous squared term. Least squares is not robust to outliers. Absolute error is much more robust, and it is exactly the property we just traded away for smoothness and a closed form.

You fit a line and the eight residuals are $+400, -400, +600, -600, +100, -100, +9000, -9000$. Which statement is true?
Why: The errors sum to exactly $0$ — and the line is terrible, since two cars are off by $\$9{,}000$. That is precisely the "Attempt 1 fails" argument: signed errors cancel, so the sum says nothing. MSE does not cancel: $\frac18(400^2+400^2+600^2+600^2+100^2+100^2+9000^2+9000^2) = \frac18(162{,}020{,}000) \approx 2.03\times10^7$, i.e. RMSE $\approx \$4{,}500$.

The derivation, line by line (with $b=0$)

The notes simplify first: set $b=0$. That forces $h(0)=0$ — every candidate line is pinned to the origin, so only the slope is free. This is not the model you'd actually ship; it is a scaffold, because with one unknown the algebra fits on half a page and every step is visible. We restore $b$ in the next section.

With $b=0$, ERM becomes a one-variable minimisation:

$$\argmin_{w \in \R}\ \frac1N\sum_{i=1}^{N}\Big(y^{(i)} - x^{(i)}w\Big)^2.$$

Step 1 — expand the square

For each $i$, $(y^{(i)} - x^{(i)}w)^2 = y^{(i)2} + x^{(i)2}w^2 - 2\,y^{(i)}x^{(i)}w$. That is just $(p-q)^2 = p^2+q^2-2pq$ with $p=y^{(i)}$, $q=x^{(i)}w$. Sum over $i$ and pull $w$ (which doesn't depend on $i$) out of each sum:

$$= \argmin_{w\in\R}\ \frac1N\left[\ \sum_{i=1}^N y^{(i)2} \;+\; w^2\sum_{i=1}^N x^{(i)2} \;-\; 2w\sum_{i=1}^N y^{(i)}x^{(i)}\ \right].$$

This is exactly the line in the notes. Everything inside the bracket is a number computed from the data except $w$. To keep the page readable, name the three data constants:

$$S \;=\; \sum_{i=1}^N x^{(i)2}, \qquad P \;=\; \sum_{i=1}^N y^{(i)}x^{(i)}, \qquad Q \;=\; \sum_{i=1}^N y^{(i)2}.$$

So we are minimising $J(w)=\frac1N\left[Q + Sw^2 - 2Pw\right]$: a parabola in $w$, opening upwards whenever $S>0$. Every parabola that opens upwards has exactly one minimum. We just have to find it.

Step 2 — completing the square

Proof

Take the two $w$-dependent terms and factor $S$ out:

$$Sw^2 - 2Pw \;=\; S\left(w^2 - \frac{2P}{S}w\right).$$

Inside the bracket, add and subtract the number that completes the square. Since $w^2 - 2\frac{P}{S}w$ is the start of $\left(w-\frac{P}{S}\right)^2 = w^2 - 2\frac{P}{S}w + \frac{P^2}{S^2}$, we add and subtract $\frac{P^2}{S^2}$:

$$= S\left[\left(w-\frac{P}{S}\right)^2 - \frac{P^2}{S^2}\right] \;=\; S\left(w-\frac{P}{S}\right)^2 - \frac{P^2}{S}.$$

Now push the $S$ inside the square, which means multiplying the bracket by $\sqrt S$ (legal because $S \geq 0$, being a sum of squares):

$$S\left(w-\frac{P}{S}\right)^2 \;=\; \left(\sqrt S\left(w - \frac{P}{S}\right)\right)^2 \;=\; \left(w\sqrt{S} \;-\; \frac{P}{\sqrt S}\right)^2,$$

using $\sqrt S \cdot \frac{P}{S} = \frac{P}{\sqrt S}$. Writing the sums back out, that inner expression is

$$w\sqrt{\sum_{i=1}^N x^{(i)2}} \;-\; \frac{\sum_{i=1}^N y^{(i)}x^{(i)}}{\sqrt{\sum_{i=1}^N x^{(i)2}}},$$

which is precisely the form in the lecture notes. Putting the whole objective back together:

$$J(w) \;=\; \frac1N\left[\left(w\sqrt S - \frac{P}{\sqrt S}\right)^2 \;+\; \underbrace{Q - \frac{P^2}{S}}_{\text{no } w \text{ in here}}\right].$$

Step 3 — why we may throw the constant away

The notes drop $Q-\frac{P^2}{S}$ without comment. Here is why that's legal, because it is a move you will make a hundred more times this semester.

Key idea

For any function $f$, any constant $c$, and any constant $\lambda > 0$:

$$\argmin_w\ \big[\lambda f(w) + c\big] \;=\; \argmin_w f(w).$$

Proof. $\lambda f(w)+c \leq \lambda f(w')+c \iff \lambda f(w) \leq \lambda f(w') \iff f(w) \leq f(w')$, the last step because dividing by a positive number preserves the inequality. So the two functions order every pair of candidates identically, and therefore have the same minimisers. $\square$

Adding $c$ slides the graph vertically; multiplying by $\lambda>0$ stretches it vertically. Neither moves the location of the bottom. Note the two caveats: the $\argmin$ is unchanged but the $\min$ value is not, and $\lambda$ must be strictly positive — $\lambda < 0$ turns a minimum into a maximum.

This is also why the $\frac1N$ never affects the answer: $\frac1N > 0$. You may minimise the sum or the mean; you get the same line, with different reported loss.

Step 4 — read off the minimiser

After dropping the constant and the $\frac1N$, we are minimising a single squared quantity:

$$\argmin_{w\in\R}\ \left(w\sqrt S - \frac{P}{\sqrt S}\right)^2.$$

A square of a real number is always $\geq 0$. So the smallest value this expression could possibly take is $0$ — and it actually attains $0$, at the $w$ that makes the inside vanish. Because the value $0$ is achievable, that $w$ is the minimiser. (This "lower bound plus achievability" argument is the whole logic of completing the square, and it is what makes the method a proof rather than a trick.)

Set the inside to zero and multiply through by $\sqrt S$:

$$w\sqrt S - \frac{P}{\sqrt S} = 0 \quad\Longleftrightarrow\quad wS - P = 0 \quad\Longleftrightarrow\quad w\sum_{i=1}^N x^{(i)2} - \sum_{i=1}^N y^{(i)}x^{(i)} = 0.$$
Key idea $$\boxed{\;w^\star \;=\; \frac{\sum_{i=1}^N y^{(i)}x^{(i)}}{\sum_{i=1}^N x^{(i)2}}\;}$$

The best-fitting line through the origin is $y = w^\star x$. Numerator: how much $x$ and $y$ move together. Denominator: how much $x$ moves at all. The minimum loss achieved is $\frac1N\left(Q - \frac{P^2}{S}\right)$ — non-zero in general, since the points don't lie on a line.

Step 5 — the calculus cross-check

Proof

Differentiate $J(w) = \frac1N\left[Q + Sw^2 - 2Pw\right]$ term by term. $Q$ is constant so contributes $0$; $\frac{d}{dw}w^2 = 2w$; $\frac{d}{dw}w = 1$:

$$\frac{dJ}{dw} \;=\; \frac1N\left[2Sw - 2P\right].$$

Set it to zero — at an interior minimum of a differentiable function the derivative vanishes:

$$2Sw - 2P = 0 \quad\Longrightarrow\quad w^\star = \frac{P}{S} = \frac{\sum_i y^{(i)}x^{(i)}}{\sum_i x^{(i)2}}.$$

The same answer. And the second derivative is $\frac{d^2J}{dw^2} = \frac{2S}{N} > 0$ whenever $S>0$, confirming it is a minimum and not a maximum or an inflection. $\square$

Intuition

Why show it twice? Because the two routes teach different things. Completing the square proves it is a global minimum with no extra work — the objective is literally a square plus a constant, so nothing anywhere in $\R$ can do better. Setting the derivative to zero only finds a stationary point; you need the second-derivative test (or convexity) to know what kind. The calculus route generalises to messy functions; the completing-the-square route generalises to matrices, which is exactly what we do further down this page.

Corner case: when is $\sum_i x^{(i)2} = 0$?

The notes ask this and leave it hanging ("Think about this situation — how would the plot of training points look like?"). Here is the answer in full.

The algebra

$S = \sum_{i=1}^N x^{(i)2}$ is a sum of squares of real numbers. Every term satisfies $x^{(i)2} \geq 0$. A sum of non-negative numbers is zero if and only if every single term is zero — if even one term were positive, no other term could cancel it, since none is negative. And $x^{(i)2}=0 \iff x^{(i)}=0$. Therefore:

$$\sum_{i=1}^N x^{(i)2} = 0 \quad\Longleftrightarrow\quad x^{(i)} = 0 \ \text{ for every } i = 1,\dots,N.$$

The picture

Every training input is $0$. Plotted, all $N$ points sit stacked on the vertical axis — a column of dots at $x=0$, at assorted heights $y^{(1)},\dots,y^{(N)}$. There is no horizontal spread at all.

Figure 2 · The degenerate scatter: every $x^{(i)} = 0$
What to notice: all four candidate lines pass through the origin and therefore all predict $\hat y = w\cdot 0 = 0$ at the only input value that appears in the data. The slope is invisible to the loss, so the loss cannot choose one.

Why the slope is genuinely undefined

Plug $x^{(i)}=0$ into the objective:

$$J(w) = \frac1N\sum_{i=1}^N\left(y^{(i)} - 0\cdot w\right)^2 = \frac1N\sum_{i=1}^N y^{(i)2} = \frac{Q}{N}.$$

$J$ does not contain $w$ at all. It is a flat function — a horizontal line, not a parabola. Every $w \in \R$ achieves exactly the same loss $Q/N$. So $\argmin_w J(w) = \R$: the argmin is not a point, it is the entire real line. There is no "the" best slope; there are infinitely many, all tied.

Said in words: every line through the origin fits these points equally well — or, more honestly, equally badly. All of them predict $0$ at $x=0$; the data never probes any other $x$, so the data has no opinion about the slope. (The one sub-case where they all fit perfectly is $y^{(i)}=0$ for all $i$ too, i.e. all the data sits at the single point $(0,0)$; then $J(w)=0$ for every $w$.)

Key idea

The formula "behaves weirdly" ($0/0$, or $P/0$) for a real reason, not a numerical accident: the problem itself has no unique answer. Division by zero in a closed form is nearly always the algebra reporting that the optimisation problem is degenerate. Never patch it; diagnose it.

The general version of this disease

In one dimension, $S = \sum_i x^{(i)2}$ is exactly $X^\top X$ for the $N\times1$ design matrix $X$ we build below. $S=0$ means the single feature column is the zero vector, so $X$ has rank $0 < 1$ — it is rank deficient. With $d$ features the same disease appears whenever the columns of $X$ are linearly dependent, and $X^\top X$ becomes singular. Same symptom (infinitely many tied optima), same cure (the feature is carrying no information the others don't already carry; drop it, or regularise). We return to this in the section on $X^\top X$ not being invertible.

Practical note: a feature that is constantly zero should never have been in your dataset. If you see $S=0$, you have found a bug in your data pipeline, not an interesting statistical situation.

Putting the intercept back: the general scalar solution

The notes set $b=0$ "for ease of understanding". Real fits need $b$ — a Pontiac Vibe with zero miles is not worth zero dollars. Here is the two-parameter solution, and it turns out to reuse everything above.

$$J(w,b) \;=\; \frac1N\sum_{i=1}^N\left(y^{(i)} - w x^{(i)} - b\right)^2.$$
Proof

Take the partial derivative with respect to $b$ first. Using the chain rule, $\frac{\partial}{\partial b}(y_i - wx_i - b)^2 = 2(y_i - wx_i - b)\cdot(-1)$:

$$\frac{\partial J}{\partial b} = -\frac2N\sum_{i=1}^N\left(y_i - wx_i - b\right) = 0 \;\Longrightarrow\; \sum_i y_i - w\sum_i x_i - Nb = 0.$$

Divide by $N$ and write $\bar x = \frac1N\sum_i x_i$, $\bar y = \frac1N\sum_i y_i$ for the sample means:

$$\boxed{\,b = \bar y - w\bar x\,}$$

Notice this holds for whatever $w$ turns out to be. It also says the residuals sum to zero at the optimum — the equation above is literally "$\sum_i \text{residual}_i = 0$". That's the intercept doing its job: sliding the line vertically until the errors balance.

Now substitute that $b$ back in. The $i$-th residual becomes

$$y_i - wx_i - (\bar y - w\bar x) \;=\; (y_i - \bar y) - w(x_i - \bar x).$$

So

$$J(w) = \frac1N\sum_{i=1}^N\Big((y_i-\bar y) - w(x_i - \bar x)\Big)^2,$$

which is exactly the $b=0$ problem we already solved, run on the centred data $\tilde x_i = x_i - \bar x$, $\tilde y_i = y_i - \bar y$. Apply $w^\star = \sum \tilde y_i\tilde x_i / \sum \tilde x_i^2$:

$$\boxed{\;w^\star = \frac{\sum_{i=1}^N (x_i - \bar x)(y_i - \bar y)}{\sum_{i=1}^N (x_i-\bar x)^2},\qquad b^\star = \bar y - w^\star \bar x.\;}\qquad\square$$
Intuition

Adding an intercept is the same as moving the origin to the centre of mass of the data and then fitting a through-the-origin line there. All the work we did with $b=0$ was not a toy after all — it was the general case in disguise.

The numerator is $N$ times the sample covariance of $x$ and $y$; the denominator is $N$ times the sample variance of $x$. So $w^\star = \widehat{\mathrm{Cov}}(x,y)/\widehat{\mathrm{Var}}(x)$: how much they move together, per unit of how much $x$ moves.

The line always passes through $(\bar x, \bar y)$

Evaluate the fitted line at $x = \bar x$:

$$h(\bar x) = w^\star \bar x + b^\star = w^\star\bar x + (\bar y - w^\star\bar x) = \bar y.$$

So the least-squares line is pinned to the centroid of the data and pivots about it as the slope changes. That is a genuinely useful fact: if you know $\bar x, \bar y$ and the slope, you know the whole line, and you can sanity-check any fit by asking whether it passes through the average point.

The corresponding corner case: the denominator $\sum_i(x_i-\bar x)^2$ is zero exactly when every $x_i$ equals $\bar x$ — all the points share one $x$-value, stacked in a vertical column (now anywhere, not just at the axis). Same disease, same diagnosis: the data never varies $x$, so it can say nothing about the slope.

Example

The eight cars, with mileage in units of 10,000 miles and price in thousands of dollars, give $\bar x = 8.275$, $\bar y = 15.25$, and

$$w^\star = -1.8906\ \text{(thousand dollars per 10{,}000 miles)}, \qquad b^\star = 30.895\ \text{(thousand dollars)}.$$

In raw units: each extra mile costs about 18.9 cents, and a zero-mileage Vibe is priced at about $\$30{,}895$. Best achievable RMSE: $\$3{,}156$ — beating the pre-reading's eyeballed "good" line, which managed $\$3{,}620$. Predicted price at 80,000 miles: $30{,}895 - 0.18906\times80{,}000 \approx \$15{,}770$.

That elongated, tilted valley is precisely the geometry that makes plain gradient descent zig-zag, which is the story of the next chapter.
On the loss surface above, you sit at some $(w,b)$ and increase $b$ by a little. The loss goes up. What can you conclude?
Why: a partial derivative tells you about one direction only. $\partial J/\partial b > 0$ says the slice of the surface at your current $w$ is rising in $b$. Because the valley is tilted, the joint optimum can still have a larger $b$ than yours — you'd just have to change $w$ at the same time. This coupling is the reason we solve for $w$ and $b$ together (or run gradient descent on both coordinates at once) rather than one at a time.

Many features: the design matrix

One number per car is not much. Real inputs have several features: mileage, age, engine size, number of previous owners. So let $\X = \R^d$ and keep $\Y = \R$. A training input is now a vector $x^{(i)} \in \R^d$, whose $j$-th coordinate $x^{(i)}_j$ is the $j$-th feature of the $i$-th car.

The hypothesis class becomes all hyperplanes: $h(x) = x^\top w + b$ with $w \in \R^d$, $b \in \R$. Written out, $x^\top w = \sum_{j=1}^d x_j w_j$ — a weighted sum of the features. Each $w_j$ says "how many dollars per unit of feature $j$".

The bias trick: absorbing $b$

Carrying $b$ around separately is a nuisance in the algebra. The standard fix, which the notes use: fix the first coordinate of every $x$ to be $1$, and stack $b$ on top of $w$:

$$x = \begin{bmatrix}1\\ x_1 \\ \vdots \\ x_{d-1}\end{bmatrix}, \qquad \theta = \begin{bmatrix} b \\ w \end{bmatrix}, \qquad\text{so}\qquad x^\top\theta = 1\cdot b + \sum_j x_j w_j = x^\top w + b.$$

Now $h_\theta(x) = x^\top\theta$ with no separate bias term — the intercept has become the weight on a constant feature. From here on, $d$ counts that constant feature, and $\theta \in \R^d$ is the single parameter vector we are solving for. (This is exactly the pre-reading's $\theta = \begin{bmatrix}b\\w\end{bmatrix}$, $x = \begin{bmatrix}1\\x\end{bmatrix}$, $y=x^\top\theta$.)

Definition

The design matrix $X \in \R^{N\times d}$ stacks the training inputs as rows, and the label vector $y \in \R^N$ stacks the labels:

$$X = \begin{bmatrix} \leftarrow\ x^{(1)\top}\ \rightarrow \\ \leftarrow\ x^{(2)\top}\ \rightarrow \\ \vdots \\ \leftarrow\ x^{(N)\top}\ \rightarrow\end{bmatrix} \in \R^{N\times d}, \qquad y = \begin{bmatrix}y^{(1)}\\ y^{(2)} \\ \vdots \\ y^{(N)}\end{bmatrix} \in \R^{N}.$$

Rows are samples, columns are features. Row $i$ is one car; column $j$ is one feature measured across all cars. The first column is all ones.

The single most useful consequence: $X\theta \in \R^N$ is the vector of all $N$ predictions at once, because row $i$ of $X\theta$ is $x^{(i)\top}\theta = h_\theta(x^{(i)})$. So $y - X\theta$ is the vector of all $N$ residuals, and

$$\|y - X\theta\|_2^2 = \sum_{i=1}^N\left(y^{(i)} - x^{(i)\top}\theta\right)^2$$

(recall $\|v\|_2^2 = \sum_k v_k^2$, the squared Euclidean length). Therefore ERM in matrix form is simply

$$\theta^\star = \argmin_{\theta \in \R^d}\ \frac1N\|y - X\theta\|_2^2.$$
Intuition

Everything you knew has been repackaged, nothing added. $N$ separate squared errors became one squared length of one residual vector in $\R^N$. Least squares is: make the residual vector short.

Answering the notes: "can you simply set $\theta = X^{-1}y$?"

The notes pose this parenthetically and answer "No." Here is why, at four levels, because the reasons are genuinely different and each one teaches something.

1. $X$ is usually not square, so $X^{-1}$ does not exist as an object

Matrix inverses are defined only for square matrices. $X$ is $N\times d$ and you normally have far more samples than features — eight cars, two parameters. $X^{-1}$ is not "hard to compute"; it is not a thing.

2. Even when $N=d$, $X$ is usually still not invertible

A square matrix is invertible only if its rows (equivalently columns) are linearly independent. Two identical cars in your dataset give two identical rows, and the matrix is singular. Two features that are the same measurement in different units give two dependent columns, same conclusion.

3. The system is overdetermined: there is no exact solution

"$\theta = X^{-1}y$" is asking for a $\theta$ with $X\theta = y$ exactly — a line that passes through every data point. With $N=8$ equations and $d=2$ unknowns, that's eight constraints on two numbers. Generic data admits no solution at all. Look at Figure 1: no straight line touches all eight dots, and no amount of algebra will produce one.

Key idea

As $\theta$ ranges over $\R^d$, the prediction vector $X\theta$ traces out exactly the column space of $X$ — the set of all linear combinations of the $d$ columns of $X$, which is a $d$-dimensional subspace sitting inside $\R^N$. When $d < N$, that is a thin slice of a big space. The label vector $y$ lives in $\R^N$ and, thanks to noise, almost surely does not lie in that slice.

So "solve $X\theta = y$" is the wrong question. The right question is: which point of the column space is closest to $y$? That is least squares, and its answer is the orthogonal projection of $y$ onto $\mathrm{col}(X)$.

Figure 5 · Least squares is a projection onto the column space
What to notice: the shortest segment from a point to a plane is the perpendicular one. Writing "perpendicular" algebraically — every column of $X$ is orthogonal to the residual, i.e. $X^\top(y - X\theta^\star) = 0$ — rearranges instantly to $X^\top X\theta^\star = X^\top y$. That is where the normal equations get their name: normal means perpendicular.

4. And even if you could invert $X$, you shouldn't want to

Suppose $N=d$ and $X$ happened to be invertible. Then $\theta = X^{-1}y$ would give a model passing exactly through every training point, including every measurement error in it. Training loss $0$, and a model that has memorised the noise. That is overfitting, and the fact that least squares refuses to interpolate when $N > d$ is a feature.

The normal equations, derived in full

Drop the $\frac1N$ (positive constant, doesn't move the argmin) and expand the squared norm using $\|v\|_2^2 = v^\top v$:

$$\argmin_\theta\ (y - X\theta)^\top(y - X\theta).$$

Step 1 — multiply it out

Use $(a-b)^\top(c-d) = a^\top c - a^\top d - b^\top c + b^\top d$ (matrix multiplication distributes) and $(X\theta)^\top = \theta^\top X^\top$ (the transpose reverses a product):

$$(y-X\theta)^\top(y-X\theta) \;=\; y^\top y \;-\; \theta^\top X^\top y \;-\; y^\top X\theta \;+\; \theta^\top X^\top X\theta.$$

Step 2 — the two middle terms are the same number

Proof

Check the shapes. $\theta^\top$ is $1\times d$; $X^\top$ is $d\times N$; $y$ is $N\times1$. So $\theta^\top X^\top y$ is a $1\times1$ matrix — a scalar. Likewise $y^\top X\theta$ is $1\times N$ times $N\times d$ times $d\times1 = 1\times 1$.

A $1\times1$ matrix is symmetric: $c^\top = c$ for a scalar $c$. And transposing the first term gives exactly the second:

$$\left(\theta^\top X^\top y\right)^\top = y^\top \left(X^\top\right)^\top \left(\theta^\top\right)^\top = y^\top X\theta.$$

A scalar equals its own transpose, so $\theta^\top X^\top y = y^\top X\theta$, and the two terms combine into $-2\theta^\top X^\top y$. $\square$

Also, $y^\top y$ contains no $\theta$ — drop it, by the same argmin rule as before. We are left with the notes' expression:

$$\argmin_\theta\ -2\theta^\top X^\top y + \theta^\top X^\top X\theta.$$

Step 3 — name the pieces

Definition $$A = X^\top X \in \R^{d\times d}, \qquad b = X^\top y \in \R^{d}.$$

(Careful: this $b$ is the notes' reuse of the letter — it is a vector, not the scalar intercept from earlier. The intercept now lives inside $\theta$.)

The analogy the notes draw: in the scalar case we had $S = \sum_i x^{(i)2}$ and $P=\sum_i y^{(i)}x^{(i)}$, and the answer was $P/S$. Here $A = X^\top X$ is the matrix version of $\sum_i x_i^2$ — its $(j,k)$ entry is literally $\sum_{i=1}^N x^{(i)}_j x^{(i)}_k$ — and $b = X^\top y$ is the matrix version of $\sum_i x_i y_i$, its $j$-th entry being $\sum_{i=1}^N x^{(i)}_j y^{(i)}$. The answer will be $A^{-1}b$: "$b$ divided by $A$".

Two facts about $A$ we will need. First, $A$ is symmetric: $A^\top = (X^\top X)^\top = X^\top (X^\top)^\top = X^\top X = A$. Second, $A$ is positive semidefinite: for any $v\in\R^d$, $v^\top A v = v^\top X^\top X v = (Xv)^\top(Xv) = \|Xv\|_2^2 \geq 0$. If $A$ is additionally invertible then $\|Xv\|^2 > 0$ for all $v \neq 0$, i.e. $A$ is positive definite. Assume that for now.

Step 4 — complete the square, in matrices

Proof

Claim. For symmetric invertible $A$,

$$-2\theta^\top b + \theta^\top A\theta \;=\; (\theta - A^{-1}b)^\top A (\theta - A^{-1}b) \;-\; b^\top A^{-1}b.$$

Verify by expanding the right-hand side. Write $m = A^{-1}b$. Then

$$(\theta-m)^\top A(\theta-m) = \theta^\top A\theta - \theta^\top A m - m^\top A\theta + m^\top A m.$$

Handle the four pieces:

  • $\theta^\top A m = \theta^\top A A^{-1} b = \theta^\top b$.
  • $m^\top A\theta = (A^{-1}b)^\top A\theta = b^\top (A^{-1})^\top A\theta$. Here symmetry is used: $A^\top = A$ implies $(A^{-1})^\top = (A^\top)^{-1} = A^{-1}$, so this is $b^\top A^{-1}A\theta = b^\top\theta$. And $b^\top\theta$ is a $1\times1$ scalar equal to its transpose $\theta^\top b$.
  • $m^\top A m = b^\top (A^{-1})^\top A A^{-1} b = b^\top A^{-1} b$ (symmetry again).

Substituting:

$$(\theta-m)^\top A(\theta-m) = \theta^\top A\theta - \theta^\top b - \theta^\top b + b^\top A^{-1}b = \theta^\top A\theta - 2\theta^\top b + b^\top A^{-1}b.$$

Subtract $b^\top A^{-1}b$ from both sides and the claim follows. $\square$

Key idea

Symmetry of $A$ is doing real work, not cosmetics. Without $A^\top = A$ the two cross terms $\theta^\top Am$ and $m^\top A\theta$ would not collapse into $2\theta^\top b$, and there would be no clean completed square. This is exactly why the derivation is stated for $A = X^\top X$: that product is symmetric no matter what $X$ is.

Step 5 — read off the minimiser

Substituting the identity, and dropping the constant $-b^\top A^{-1}b$ (no $\theta$ in it):

$$\argmin_\theta\ (\theta - A^{-1}b)^\top A(\theta - A^{-1}b).$$

Since $A = X^\top X$, this quadratic form is

$$(\theta - A^{-1}b)^\top X^\top X(\theta - A^{-1}b) = \big\|X\left(\theta - (X^\top X)^{-1}X^\top y\right)\big\|_2^2,$$

which is the notes' final line. A squared norm is $\geq 0$, and it hits $0$ when its argument does, at $\theta = A^{-1}b$ — achievable, so it is the minimum. (With $A$ positive definite it is the unique minimiser: any $\theta \ne A^{-1}b$ gives a strictly positive value.)

Key idea $$\boxed{\;\theta^\star \;=\; A^{-1}b \;=\; \left(X^\top X\right)^{-1}X^\top y\;}$$

The normal equations. Compare the scalar answer $w^\star = P/S$: same formula, with $S \to X^\top X$, $P \to X^\top y$, and "divide" $\to$ "multiply by the inverse". In practice nobody forms the inverse; you solve the linear system $(X^\top X)\theta = X^\top y$, which is faster and numerically far better behaved.

Step 6 — the calculus route, for cross-check

The optimization chapter proves the two vector-calculus identities $\nabla_\theta(\theta^\top v) = v$ and $\nabla_\theta(\theta^\top A\theta) = (A + A^\top)\theta$. Apply them to $J(\theta) = y^\top y - 2\theta^\top X^\top y + \theta^\top X^\top X\theta$:

$$\nabla_\theta J(\theta) \;=\; 0 \;-\; 2X^\top y \;+\; (X^\top X + (X^\top X)^\top)\theta \;=\; -2X^\top y + 2X^\top X\theta,$$

using symmetry of $X^\top X$ in the last step. Setting $\nabla_\theta J = 0$:

$$2X^\top X\theta = 2X^\top y \quad\Longrightarrow\quad X^\top X\theta = X^\top y \quad\Longrightarrow\quad \theta^\star = (X^\top X)^{-1}X^\top y.$$

Same answer, third time. And notice that $X^\top X\theta = X^\top y$ rearranges to $X^\top(y - X\theta) = 0$ — the geometric statement from Figure 5 that the residual is orthogonal to every column of $X$. Algebra, calculus and geometry all land on the same equation.

Guided problemNormal equations by hand, with a 2×2 inverse

Three points: $(x,y) = (0,1),\ (1,2),\ (2,5)$. Fit $h(x) = wx + b$ using $\theta^\star = (X^\top X)^{-1}X^\top y$ with the bias absorbed. Do every arithmetic step.

Reminder: $\begin{bmatrix}p&q\\r&s\end{bmatrix}^{-1} = \dfrac{1}{ps-qr}\begin{bmatrix}s&-q\\-r&p\end{bmatrix}$.

Step 1 — Build $X$ and $y$

Absorbing the bias means each input becomes $\begin{bmatrix}1 \\ x\end{bmatrix}$ and $\theta = \begin{bmatrix}b\\w\end{bmatrix}$. Rows of $X$ are the inputs:

$$X = \begin{bmatrix}1 & 0\\ 1 & 1\\ 1 & 2\end{bmatrix} \in \R^{3\times2}, \qquad y = \begin{bmatrix}1\\2\\5\end{bmatrix}\in\R^3.$$

Sanity check: $N=3$ rows, $d=2$ columns. The first column is all ones — that's the constant feature.

Step 2 — Compute $A = X^\top X$

$X^\top = \begin{bmatrix}1&1&1\\0&1&2\end{bmatrix}$ is $2\times3$, so $A$ is $2\times2$. Entry $(j,k)$ is the dot product of column $j$ and column $k$ of $X$:

  • $A_{11} = 1^2+1^2+1^2 = 3$ (this is always $N$ for the ones-column)
  • $A_{12} = A_{21} = 1\cdot0 + 1\cdot1 + 1\cdot2 = 3$ (this is $\sum_i x_i$)
  • $A_{22} = 0^2+1^2+2^2 = 5$ (this is $\sum_i x_i^2$)
$$A = \begin{bmatrix}3 & 3\\ 3 & 5\end{bmatrix}.$$

Symmetric, as promised.

Step 3 — Compute $b = X^\top y$
  • First entry: $1\cdot1 + 1\cdot2 + 1\cdot5 = 8$ (this is $\sum_i y_i$)
  • Second entry: $0\cdot1 + 1\cdot2 + 2\cdot5 = 12$ (this is $\sum_i x_iy_i$)
$$b = \begin{bmatrix}8\\12\end{bmatrix}.$$
Step 4 — Invert $A$

$\det A = 3\cdot5 - 3\cdot3 = 15 - 9 = 6 \neq 0$, so the inverse exists.

$$A^{-1} = \frac16\begin{bmatrix}5 & -3\\ -3 & 3\end{bmatrix}.$$

Check: $A^{-1}A = \frac16\begin{bmatrix}5\cdot3-3\cdot3 & 5\cdot3-3\cdot5\\ -3\cdot3+3\cdot3 & -3\cdot3+3\cdot5\end{bmatrix} = \frac16\begin{bmatrix}6&0\\0&6\end{bmatrix} = I$. ✓

Step 5 — Multiply
$$\theta^\star = A^{-1}b = \frac16\begin{bmatrix}5&-3\\-3&3\end{bmatrix}\begin{bmatrix}8\\12\end{bmatrix} = \frac16\begin{bmatrix}40-36\\ -24+36\end{bmatrix} = \frac16\begin{bmatrix}4\\12\end{bmatrix} = \begin{bmatrix}2/3\\ 2\end{bmatrix}.$$

So $b^\star = 2/3$ and $w^\star = 2$: the fitted line is $h(x) = 2x + \tfrac23$.

Answer & the takeaway

$h(x) = 2x + \tfrac23$. Cross-check with the scalar with-intercept formulas: $\bar x = 1$, $\bar y = 8/3$.

$$w^\star = \frac{(-1)(1-\tfrac83) + 0 + (1)(5-\tfrac83)}{(-1)^2+0^2+1^2} = \frac{\tfrac53 + \tfrac73}{2} = \frac{4}{2} = 2,\qquad b^\star = \tfrac83 - 2\cdot1 = \tfrac23.\ \checkmark$$

Residuals: $1 - \tfrac23 = \tfrac13$; $2 - \tfrac83 = -\tfrac23$; $5-\tfrac{14}{3} = \tfrac13$. They sum to $\tfrac13-\tfrac23+\tfrac13 = 0$, exactly as the $\partial J/\partial b = 0$ condition predicted.

Takeaway: every entry of $A$ and $b$ was a familiar scalar sum in disguise. The matrix machinery is bookkeeping for sums you already know how to compute — its value is that it keeps working when $d = 500$.

Corner case: when $X^\top X$ is not invertible

The notes flag this and say "you don't have to worry about it". You should at least be able to recognise it, so here is the short version.

When does it happen?

$\det(X^\top X) = 0$ exactly when $\mathrm{rank}(X) < d$, i.e. the columns of $X$ are linearly dependent. Two ways to arrive there:

  • Fewer samples than features, $N < d$. Then $\mathrm{rank}(X) \leq N < d$ automatically. This is routine in genomics (20,000 gene-expression features, 100 patients) and in text (a 50,000-word vocabulary, 2,000 documents). Geometrically: $d$ vectors in $\R^N$ with $d > N$ cannot be independent.
  • Redundant features. A feature repeated twice; a feature that is a fixed multiple of another; a set of one-hot indicator columns that sum to the all-ones intercept column (the "dummy variable trap").
Example

You record each car's weight twice — once in thousands of kilograms, once in thousands of pounds — so column 2 is $2.2\times$ column 1:

$$X = \begin{bmatrix}1 & 2.2\\ 2 & 4.4\\ 3 & 6.6\end{bmatrix},\qquad X^\top X = \begin{bmatrix}1+4+9 & 2.2+8.8+19.8\\ 2.2+8.8+19.8 & 4.84+19.36+43.56\end{bmatrix} = \begin{bmatrix}14 & 30.8\\ 30.8 & 67.76\end{bmatrix}.$$ $$\det = 14\times67.76 - 30.8^2 = 948.64 - 948.64 = 0.$$

Singular. And you can see why the fit is ambiguous: if $\theta = (\theta_1,\theta_2)$ fits, so does $(\theta_1 + 2.2c,\ \theta_2 - c)$ for any $c$ — the two features can trade weight freely without changing a single prediction. "Kilograms matter and pounds don't" and "pounds matter and kilograms don't" are the same model.

What it means

If $v \neq 0$ satisfies $Xv = 0$ (a null-space direction — which exists precisely when the columns are dependent), then for any optimal $\theta^\star$,

$$X(\theta^\star + cv) = X\theta^\star + cXv = X\theta^\star \quad\text{for every } c \in \R.$$

Identical predictions, identical loss. So there are infinitely many optima, forming a whole line (or plane, or...) of tied solutions. Crucially the projection $\hat y = X\theta^\star$ is still unique — Figure 5 still has exactly one closest point in the plane. What is not unique is the coordinates $\theta$ you use to name that point.

What the pseudo-inverse picks beyond syllabus

The Moore–Penrose pseudo-inverse $X^+$ is defined for every matrix, square or not, invertible or not, and $\theta = X^+y$ always returns a least-squares solution. Among the infinitely many tied optima it selects a specific one: the one with the smallest $\|\theta\|_2$. In the kilograms/pounds example it splits the weight between the two columns rather than dumping it all on one, which is the least arbitrary choice available. When $X^\top X$ is invertible, $X^+ = (X^\top X)^{-1}X^\top$ and you recover the normal equations exactly, so nothing is lost by always using it. In code, numpy.linalg.lstsq does this for you; numpy.linalg.inv will simply blow up.

The other standard fix is ridge regression: minimise $\|y-X\theta\|^2 + \lambda\|\theta\|^2$ for some $\lambda > 0$, whose solution is $(X^\top X + \lambda I)^{-1}X^\top y$. Adding $\lambda I$ shifts every eigenvalue of $X^\top X$ up by $\lambda$, so the matrix is invertible for any data. beyond syllabus

You have $N=50$ documents and $d=5{,}000$ word-count features. What happens if you try $\theta = (X^\top X)^{-1}X^\top y$?
Why: $X^\top X$ is always square ($d\times d$) — squareness is never the problem. Rank is. $\mathrm{rank}(X^\top X) = \mathrm{rank}(X) \le \min(N,d) = 50$, far below $5{,}000$, so the determinant is $0$. With $d \gg N$ you can fit the 50 labels perfectly in infinitely many ways; the training loss is $0$ for a whole $4{,}950$-dimensional family of $\theta$. You need the pseudo-inverse, or regularisation, or fewer features — and you should be very suspicious of the resulting test error.

What it costs, and why the next chapter exists

The closed form is wonderful. It is also, for large $d$, unusable. Count the operations:

StepWhat it doesCost
$X^\top X$$d^2$ entries, each a dot product of two length-$N$ columns$O(Nd^2)$
$X^\top y$$d$ entries, each a length-$N$ dot product$O(Nd)$
Solve $(X^\top X)\theta = X^\top y$Cholesky factorisation of a $d\times d$ system$O(d^3)$
Total$\mathbf{O(Nd^2 + d^3)}$

Also $O(d^2)$ memory, just to hold $X^\top X$.

Example
  • $d = 10$, $N = 10^6$. $Nd^2 = 10^8$ operations. Instant. Use the closed form, always.
  • $d = 1{,}000$, $N = 10^6$. $Nd^2 = 10^{12}$, $d^3=10^9$. Minutes on a laptop, plus 8 MB for $X^\top X$. Still fine.
  • $d = 10^5$ (a modest last layer, or bag-of-words). $d^3 = 10^{15}$ operations and $d^2 = 10^{10}$ entries $\approx$ 80 GB of memory just for $X^\top X$. Hopeless. And the cubic term doesn't care how much data you have — it is pure dimension.
Key idea

Gradient descent computes $\nabla_\theta J = -2X^\top y + 2X^\top X\theta$, but it never forms $X^\top X$. It evaluates $X^\top(X\theta)$ as two matrix–vector products: $O(Nd)$ per iteration, $O(d)$ memory. Run it for $T$ iterations and you pay $O(TNd)$ — linear in $d$, not cubic. For $d = 10^5$ that is the difference between "runs in a minute" and "does not run".

And linear regression is the easy case: it is one of the very few models with any closed form at all. Logistic regression has none. Neural networks have none. Gradient descent is the general-purpose answer, and it is the subject of the next chapter.

Guided problemA fit from summary statistics — should I sell the Vibe?

Someone hands you only these numbers for the eight cars (mileage in miles, price in dollars): $\bar x = 82{,}750$, $\bar y = 15{,}250$, $\sum_i (x_i-\bar x)(y_i-\bar y) = -2.1268\times10^9$, $\sum_i (x_i-\bar x)^2 = 1.1249\times10^{10}$.

(a) Find the fitted line. (b) Predict the price of a Vibe with 80,000 miles. (c) The car actually has 140,000 miles; what does the model say, and what should you notice?

Step 1 — Which formula applies?

We want an intercept (a zero-mileage car is not free), so use the centred formulas, not $P/S$:

$$w^\star = \frac{\sum_i(x_i-\bar x)(y_i-\bar y)}{\sum_i(x_i-\bar x)^2},\qquad b^\star = \bar y - w^\star\bar x.$$

Note we never needed the raw data — those four summaries are sufficient.

Step 2 — Slope and intercept
$$w^\star = \frac{-2.1268\times10^9}{1.1249\times10^{10}} = -0.18906\ \text{dollars per mile}.$$ $$b^\star = 15{,}250 - (-0.18906)(82{,}750) = 15{,}250 + 15{,}645 = 30{,}895\ \text{dollars}.$$

So $h(x) = 30{,}895 - 0.18906\,x$. Sign check: the slope is negative, which is what "more miles, less money" should look like. If you got a positive slope, you swapped the sign somewhere.

Step 3 — Predict at 80,000 miles
$$h(80{,}000) = 30{,}895 - 0.18906\times80{,}000 = 30{,}895 - 15{,}125 = 15{,}770.$$

About $\$15{,}770$. Sanity check with the centroid property: $80{,}000$ is just below $\bar x = 82{,}750$, and indeed $15{,}770$ is just above $\bar y = 15{,}250$. The line passes through $(\bar x,\bar y)$, so predictions near the mean mileage should land near the mean price.

Step 4 — Predict at 140,000 miles, and be suspicious
$$h(140{,}000) = 30{,}895 - 0.18906\times140{,}000 = 30{,}895 - 26{,}468 = 4{,}427.$$

About $\$4{,}427$. Two things to notice.

(i) Extrapolation. $140{,}000$ is inside the training range ($25{,}000$–$160{,}000$), so this is interpolation and reasonably trustworthy. But the same formula at $x = 200{,}000$ gives $30{,}895 - 37{,}812 = -\$6{,}917$: a negative price. The model has no idea that prices are bounded below by zero. A line is linear everywhere, including where reality is not.

(ii) RMSE is $\$3{,}156$. Against a prediction of $\$4{,}427$ that is a huge relative uncertainty. A point estimate without its error bar is a half-answer.

Answer & the takeaway

(a) $h(x) = 30{,}895 - 0.18906x$. (b) $\approx\$15{,}770$. (c) $\approx\$4{,}427$, with RMSE $\approx\$3{,}156$, and the model goes negative beyond about $163{,}400$ miles.

Takeaway: the fit depends on the data only through four summary numbers, the fitted line always passes through $(\bar x,\bar y)$, and the model's confident-looking arithmetic says nothing about whether a line was the right hypothesis class. Checking that is what train/test splits are for.

Guided problemDiagnose three broken designs

For each, say whether the closed-form solution is unique, and why.

(A) $b=0$ model, data $(0,4),(0,-1),(0,7)$.    (B) with-intercept model, data $(5,3),(5,9),(5,1)$.    (C) $d=3$ features (constant, mileage, mileage-in-kilometres), $N=100$ cars.

(A) — do the arithmetic before reasoning

$S=\sum x_i^2 = 0+0+0 = 0$ and $P = \sum x_iy_i = 0$. The formula reads $0/0$: undefined. And indeed $J(w) = \frac13(16+1+49) = 22$ for every $w$ — flat. Infinitely many optima; the slope is unidentifiable because the data never varies $x$. This is exactly the notes' corner case.

(B) — same disease, shifted

$\bar x = 5$, so every $(x_i - \bar x) = 0$ and the denominator $\sum(x_i-\bar x)^2 = 0$. Undefined again. Picture: three points stacked vertically at $x=5$. Any line through $(5,\bar y) = (5,\tfrac{13}{3})$ fits identically, whatever its slope. The intercept did not save us: the problem is zero horizontal spread, not the position of the origin.

(C) — rank deficiency with plenty of data

Column 3 is $1.609\times$ column 2, so $\mathrm{rank}(X) = 2 < 3 = d$ even though $N=100 \gg d$. $X^\top X$ is $3\times3$ with determinant $0$. Not unique: shifting weight between the miles column and the kilometres column leaves every prediction untouched. Lots of data does not fix redundant features. Answer & the takeaway

None of the three has a unique solution. (A) and (B) are the scalar corner case — zero variation in $x$. (C) is its multivariate form — linearly dependent columns.

Takeaway: "the denominator is zero" and "$X^\top X$ is singular" are the same statement at two different values of $d$. In both cases the fitted predictions may still be perfectly well defined; it is the parameters that are ambiguous. If your job is prediction you can shrug; if your job is to interpret the coefficients ("how much is a mile worth?"), you cannot.

Which of these is not a valid reason that $\theta^\star = (X^\top X)^{-1}X^\top y$ rather than $X^{-1}y$?
Why: $X^\top X$ is not always invertible — that's the whole point of the pseudo-inverse discussion. It is invertible exactly when $X$ has full column rank, which fails when $N < d$ or when features are redundant. The other two statements are correct and are the real reasons.

Recap

Scalar

One feature

Through the origin: $w^\star=\dfrac{\sum_i y_ix_i}{\sum_i x_i^2}$. With intercept: $w^\star = \dfrac{\sum_i(x_i-\bar x)(y_i-\bar y)}{\sum_i(x_i-\bar x)^2}$, $b^\star=\bar y - w^\star\bar x$, and the line passes through $(\bar x,\bar y)$. Breaks when $x$ has no spread.

Vector

$d$ features

Absorb $b$ as a constant-1 feature, stack samples as rows of $X$. $\theta^\star=(X^\top X)^{-1}X^\top y$, the orthogonal projection of $y$ onto $\mathrm{col}(X)$. Breaks when $\mathrm{rank}(X) < d$; use the pseudo-inverse.

  • Squared loss, because errors must not cancel, we want smoothness, and we want the mean.
  • Completing the square proves a global optimum; setting the derivative to zero finds a stationary point. Both give the same formula, three times over.
  • Dropping $\theta$-independent constants and positive scale factors inside an $\argmin$ is always legal and always worth doing.
  • A zero denominator is never a numerical nuisance — it is the algebra reporting that the problem has infinitely many answers.
  • The closed form costs $O(Nd^2 + d^3)$. That cubic term is why gradient descent exists.
